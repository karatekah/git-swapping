# GithubSwapping v0.1.0-alpha.2

Experimental release of the per-repository PowerShell workflow, with corrected Windows CI.

## Included

The `git-profile` command supports `list`, `current`, `use`, `check`, `status` and `help`. Profiles are local data files, with an example included in the repository. Updates validate the GitHub owner and both fetch/push destinations, respect config locks and replace the local configuration after all writes succeed.

The function is loaded from `$PROFILE` and does not change global Git settings or credential storage. Account data remains outside version control. English, Spanish and Italian overviews document the same workflow.

## Changes from alpha.1

Windows PowerShell 5.1 and PowerShell 7 now run in explicit CI jobs. This fixes the workflow validation error that prevented alpha.1 jobs from starting. The repository profile behavior is unchanged.

## Verification

The regression suite has 27 checks using real temporary repositories with isolated Git configuration and example identities. It covers profile assignment, idempotence, owner mismatches, separate push URLs, unsupported origins, multiple URLs, existing locks, failed staged writes and effective identity overrides.

Run `tests/git-profile.Tests.ps1` with Windows PowerShell 5.1 or PowerShell 7. GitHub Actions runs the same suite on both shells. No test contacts GitHub, reads stored credentials or modifies real projects.

## Known limits

- Windows only; Git 2.31 or later, PowerShell 5.1 or 7.
- Normal working repositories; HTTPS on `github.com` with a single fetch URL and at most one explicit push URL.
- The configured account must be the owner. Organization and shared-repository mappings are not supported.
- Configuration symlinks, bare repositories, SSH, GitHub Enterprise and multiple URLs are rejected.
- `use` saves configuration; `check` separately detects effective identity overrides. Neither command authenticates remotely or tests push permissions.
- The loader points to the local clone. Update `$PROFILE` if the clone moves.
- Profile installation is manual; keep your ignored `profiles.psd1` backed up.

Report reproducible failures through the repository's issues. Remove account data and credentials from diagnostic output before sharing it.
