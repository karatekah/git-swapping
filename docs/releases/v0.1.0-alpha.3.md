# Git Swapping v0.1.0-alpha.3

This alpha adds guided installation, interactive profile management and a preview for per-repository configuration.

- Run `install.ps1` to set up accounts. Existing installations can keep their `profiles.psd1`.
- Run `git-profile use -Auto -WhatIf` inside a repository to preview the GitHub owner match and the identity and URL changes. Run `git-profile use -Auto` to apply them.
- Run `git-profile status` to see the expected profile, effective identities and sources of conflicting Git settings. Origin URLs outside the supported format are hidden from diagnostics.
- Git resolves the proposed fetch and push URLs before Git Swapping replaces the repository config. Profile edits preserve names and comments in UTF-8 files.

Git Swapping supports Windows PowerShell 5.1 and PowerShell 7 on Windows with Git 2.31 or later. The isolated test suite uses Git 2.32 or later. See the [README](../../README.md) for supported remotes, [CI](https://github.com/karatekah/git-swapping/actions/workflows/ci.yml) for test runs, and the [changelog](../../CHANGELOG.md) for the full list of changes.
